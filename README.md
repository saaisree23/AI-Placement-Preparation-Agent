# AI Placement Preparation Agent 

An intelligent, AI-powered placement preparation assistant that helps students prepare for their dream jobs with personalized career guidance and company-specific interview preparation.

## Features

* **Personalized Preparation Plans:** Generates plans based on student profiles and target companies.
* **Company Research:** Uses Tavily Search to retrieve company-related interview information and technical requirements.
* **Resume Optimization:** Provides suggestions to improve resumes.
* **Skills Gap Analysis:** Identifies skills to focus on for the target role.
* **Interview Preparation:** Generates technical and HR interview questions.
* **PDF Report Generation:** Exports the personalized placement plan as a PDF.

## Tech Stack

* Python
* LangChain
* Ollama (Llama 3)
* Tavily Search API
* ReportLab

## Project Objective

To help students prepare for placements more effectively through personalized AI-generated guidance, company research, and structured interview preparation.
